# Nome e projetos semelhantes: pesquisa de 2026-11-27

O projeto nasceu com o nome de trabalho VibeGuard. A busca de 2026-11-27 encontrou usos existentes do mesmo nome ou de nome muito próximo e, com base nela, o nome passou a ser Contraprova. A decisão está em [ADR-0004](../adr/0004-nome-do-projeto-contraprova.md); a busca de marcas, que continua pendente, está em [PA-10](../perguntas-em-aberto.md).

As descrições abaixo usam apenas o que foi encontrado na busca. Não se afirma nada sobre as funcionalidades desses projetos além disso.

## O que isso significa

- O nome Contraprova está livre nos registros de pacotes conferidos, mas nomes livres hoje não estão reservados.
- Os 14 repositórios homônimos no GitHub não têm estrelas; isso indica baixo risco de confusão, mas não foi avaliado do ponto de vista de marca.
- Enquanto a busca de marcas não for feita, a documentação não deve afirmar que o nome está livre de conflitos de marca.

## Critérios usados para escolher o nome

O manifesto não cita critérios para o nome. Os critérios usados são os do [ADR-0004](../adr/0004-nome-do-projeto-contraprova.md):

- expressar a ideia central do projeto;
- estar livre nos registros de pacotes conferidos (npm, PyPI e crates.io).

A fonte [Starting an Open Source Project](https://opensource.guide/starting-a-project/) recomenda checar conflitos de nome e de marca. A checagem de marca continua pendente.
