# Pesquisa

Registro da pesquisa feita em 2026-11-27 para montar a estrutura do repositório. Cada página diz o que foi lido, o que foi adotado e onde, e o que não pôde ser confirmado. As fontes são externas e podem mudar; a data de leitura é 2026-11-27.

| Documento | Conteúdo |
|---|---|
| [boas-praticas-open-source.md](boas-praticas-open-source.md) | Práticas de projetos open source, políticas de IA, instruções para agentes, segurança do repositório, documentação e versionamento |
| [nome-e-projetos-semelhantes.md](nome-e-projetos-semelhantes.md) | Conflitos de nome encontrados e o que não foi pesquisado |

## Regras deste registro

- Só entram aqui fontes que foram efetivamente lidas na data indicada. Nenhuma prática é citada de memória.
- O que não pôde ser lido ou confirmado é dito como não verificado.
- A pesquisa não define decisões: as decisões estão nos [ADRs](../adr/README.md), e os pontos ainda abertos em [perguntas-em-aberto.md](../perguntas-em-aberto.md).
- Novas pesquisas são adicionadas com data própria, sem sobrescrever as anteriores.
